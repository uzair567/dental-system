How syncing works

Everything you enter here is saved to this computer immediately, even with no internet connection. Every 20 seconds — and whenever you press Sync Now — the app checks the live server. If it's reachable, unsynced records are pushed up, and anything new from the website or the web dashboard is pulled down, so this computer and the live server stay in agreement.
